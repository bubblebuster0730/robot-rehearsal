지표 전체

반복 평균. 차이는 같은 입주민끼리 짝지어 뺀 값의 평균 ± 95% 신뢰구간

입주민 유형별 LLM 가설

유형·비율·확률·속마음 한 줄은 LLM이 만든 설정입니다. 계산은 시뮬레이터가 합니다.
실행 중인 파이썬 코드 보기 (simulate.py)
엔진이 준비되면 표시됩니다.
같은 코드

영상 수치를 만든 simulate.py를 고치지 않고 실행합니다. 기본 설정이면 영상과 같은 값이 나옵니다.

같은 입주민끼리 비교

시드 1000~1029로 만든 입주민 30세트를 세 조건에 똑같이 넣습니다. 그래서 차이는 조건 때문에 생깁니다.

로봇 없음 · 기존안도 다시 계산

가정값을 바꾸면 비교 대상도 같은 가정값으로 다시 계산합니다. 승강기 추가는 내 설정에만 적용합니다.

한계

실제 승강기 운행 기록으로 보정하기 전입니다. 계산이 맞는지는 표준 상향피크 공식과 1.3% 이내로 확인했지만, 현실과 같다는 뜻은 아닙니다.
